# Decision boundary

Publisher record -> both sides' complete semantic preference partitions -> exact validator agreement -> unknown gate -> deterministic deferred acceptance -> seat/acceptability/stability checks -> append-only batch result.

A candidate being desirable to an applicant says nothing about whether the placement accepts that applicant. Both directions are independently derived. Invalid or omitted profile fields fail parsing; an explicit UNKNOWN is a valid unresolved decision and prevents assignment. Negative and uncertain outputs are independently checked, not merely permitted enum values.

Canonicalization sorts IDs only inside explicitly declared ties and rejected/unknown lists using immutable roster order. Tier order remains consequential and must match exactly. Quotes may differ across independent extractions; the leader's chosen quotes must pass separate full-source relevance judgments.

Each applicant proposes to a placement at most once. At most 20 proposals are possible under constructor bounds. Placements use a responsive ranking over individuals and fixed capacities; quotas by subgroup, couples, complementarities and changing capacity are outside this model.

For any unmatched applicant-placement pair acceptable to both sides, a blocking pair would exist if the applicant prefers that placement to its current assignment (or is unmatched) and the placement either has a free seat or prefers the applicant to a current holder. The contract independently scans this condition after deferred acceptance. A nonempty scan reverts rather than storing an unstable result.

Ties are refined deterministically before solving. Applicant optimality concerns the refined strict profile, not all possible resolutions of the original ties. The primitive does not maximize cardinality over alternative tie-breaks.

The four live fixtures exercise cascading displacement, declared ties, nonreciprocal acceptance leaving a seat vacant, and unresolved preference review. Profile declarations are legitimate preference inputs rather than factual service-delivery certifications. The fixed publisher remains a trust boundary.
